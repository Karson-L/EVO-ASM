# EVO-ASM 实验设计方案 (EXPERIMENTS.md)

> 基于 MODEL_SPEC.md v1.0 | 论文：《基于演化ABM的量化交易策略生态系统与Alpha消失机制研究》
> 设计原则：四组递进实验，从静态基线到完整演化，逐步剥离 Alpha 衰减的因果机制

---

## 实验逻辑链

```
E1: 无演化（基线）
 │  固定策略 + 固定财富 → 策略分布静态
 │  研究问题：无演化时市场是否自发产生 Alpha 衰减？
 │
 ├─► E2: 资本扩张
 │  固定策略 + 财富重分配 → 资本向盈利策略集中
 │  研究问题：财富集中（策略拥挤）单独驱动 Alpha 衰减吗？
 │
 ├─► E3: 复制机制
 │  策略复制（无突变）+ 财富重分配 → 成功策略被克隆
 │  研究问题：策略模仿如何导致多样性丧失？
 │
 └─► E4: 复制+突变（完整演化）
     达尔文式全循环 → 策略协同演化
     研究问题：突变能否维持多样性以对抗 Alpha 衰减？
```

## 通用设定（跨实验不变）

### 固定控制变量

| 变量 | 符号 | 固定值 | 理由 |

| 资产数量 | N | 1 | 隔离策略交互，排除跨资产效应 |
| 模拟期数 | T | 10000 | 覆盖多轮演化周期 |
| 信号维度 | D | 6 | MODEL_SPEC 标准配置 |
| 市场出清敏感度 | κ | 0.001 | 中等价格弹性 |
| 基础价值波动率 | σ_F | 0.01 | 日波动~1% |
| 均值回复强度 | φ | 0.001 | 弱均值回复 |
| 涨跌停板 | ℓ | ±10% | 中国A股标准 |
| 佣金费率 | c_comm | 0.0003 | A股万三 |
| 印花税率 | c_stamp | 0.001 | A股千一（卖方） |
| 无风险利率 | r_f | 0.0 | 简化 |

| 随机种子 | seed | {42, 123, 456, 789, 1024} | 5 次独立复现 |

### 初始化统一规则

- 所有 agent 初始财富均等：`W_i(0) = W_total / M = 20,000`
- 初始持仓 `h_i(0) = 0`
- 初始策略随机生成：`Strategy.random(D=6, rng=seed_rng)`
- 每个 agent 的 `ancestor_id = agent_id`（独立祖源）
- 市场初始价格 `P(0) = F_bar = 100`

## Experiment 1: 无演化基线

### 研究问题

> 在策略分布完全静态的封闭市场中，Alpha 是否仍然衰减？市场是否自发趋向有效？

### 假说映射

对应 **H1（弱有效市场涌现假说）** 的部分否定检验：
若 E1 中发现显著 Alpha 持续存在 → 演化机制是 Alpha 衰减的必要条件。

### 实验处理

**演化开关**：全部关闭
- 无淘汰（P_eliminate = 0）
- 无复制
- 无突变
- 无财富重分配

每个 agent 在整个模拟期间保持其初始策略 `π_i(0)` 不变，财富仅通过交易盈亏自然变化。

### 自变量

| 自变量 | 取值 | 目的 |
|--------|------|------|
| 策略初始多样性 | 低（σ_init=0.02）/ 中（0.10）/ 高（0.30） | 检验初始策略分布对长期结果的影响 |
| 噪声交易冲击 | σ_noise ∈ {0.0, 0.005, 0.02} | 外部噪声如何创造/消除套利机会 |

**实验矩阵**：3 × 3 = 9 组条件 × 5 seeds = 45 次运行

### 因变量（E1 专用）

| 因变量 | 定义 |
|--------|------|
| 策略 Alpha 持续性 | 初始阶段末（t=1000）与终态（t=9000-10000）各策略家族的平均 α_k |
| 幸存者偏差 | 简单策略（动量/均值回复）vs 复杂策略的长期存活率 |
| 价格偏离度 | MAE(P_t, F_t) / F_t 的时序均值 |
| 收敛时间 | |ACF(1)| 首次低于 0.05 的期数（若发生） |

### 预期输出图表

| 图号 | 内容 | 类型 |
|------|------|------|
| Fig 1.1 | 价格 P(t) vs 基础价值 F(t) | 双线时间序列 |
| Fig 1.2 | 对数收益率 r(t) 分布 vs 正态分布 | QQ-plot + 直方图叠加 |
| Fig 1.3 | 波动率聚集：|r(t)| 的 ACF | 柱状图（lag 1-30） |
| Fig 1.4 | 策略熵 H_strat(t) — 应恒定 | 水平线时间序列 |
| Fig 1.5 | 各策略家族 Alpha 持续性热图 | 热力图（家族×时间窗口） |

| Fig 1.8 | 不同 σ_noise 下的市场效率 ρ₁ 对比 | 分面时间序列（3 panel） |

### 统计指标

| 指标 | 方法 | 报告格式 |
|------|------|----------|
| 收益率正态性 | Jarque-Bera 检验 | JB 统计量 + p 值 |
| 长记忆性 | Hurst 指数（R/S 法） | H ± 95% CI |
| Alpha 显著性 | 单样本 t 检验（α_k vs 0） | t 统计量 + p 值 + Cohen's d |
| 组间差异（σ_noise 影响） | 单因素 ANOVA（σ_noise 三水平 × ρ₁） | F 统计量 + η² |
| 时间稳定性 | Chow 断点检验（t=5000 处） | F 统计量 + p 值 |

### 预期发现

1. σ_noise=0 时，市场可能达到高效率（ρ₁≈0），但收敛速度取决于初始策略多样性
2. σ_noise>0 时，噪声本身创造套利机会，效率有限
3. 无演化条件下，策略分布完全静态，H_strat 恒定——策略多样性不会自发衰减

## Experiment 2: 资本扩张

### 研究问题

> 当资本根据表现流向盈利策略（但不改变策略本身）时，策略拥挤是否单独驱动 Alpha 衰减？

### 假说映射

对应 **H2（Alpha 生命周期假说）** 的拥挤驱动分量：
- H2a：拥挤度 C_k 上升 → Alpha α_k 下降
- H2b：资本流出 → Alpha 部分恢复（检验是否存在无演化下的恢复）

### 实验处理

**资本扩张机制**：每 K=200 期执行一次资本重分配
- 表现最差的 P_eliminate=20% agent 的财富被没收
- 没收财富按适应度比例分配给幸存者
- **策略不变**（无复制、无突变）
- Agent 数量保持恒定 M=500（通过"破产重生"机制：淘汰 agent 以全新随机策略+最低财富重生）

### 自变量

| 自变量 | 取值 | 目的 |
|--------|------|------|
| 资本重分配周期 | K ∈ {50, 200, 500} | 检验资本流动速度的影响 |
| 淘汰/重生比例 | P_eliminate ∈ {0.10, 0.20, 0.40} | 检验选择强度的作用 |
| 初始策略多样性 | σ_init ∈ {0.05, 0.10, 0.30} | 控制初始条件 |

**实验矩阵**：3 × 3 × 3 = 27 组 × 5 seeds = 135 次运行

### 因变量（E2 专用）

| 因变量 | 定义 |
|--------|------|
| 策略拥挤度 C_k(t) | 策略家族 k 的财富占市场总财富比例 |
| 拥挤度- Alpha 弹性 ε_α(k) | d(ln α_k) / d(ln C_k)（见 MODEL_SPEC §8.9） |
| 资本集中度 | Top-5 家族的财富占比 |
| 资本流动速度 | 每 K 期财富重分配的绝对值占总财富比例 |
| 重生策略存活率 | 破产重生后的新策略在 500 期内的存活比例 |

### 预期输出图表

| 图号 | 内容 | 类型 |
|------|------|------|
| Fig 2.1 | C_k(t) vs α_k(t) 双轴时间序列（top-3 家族） | 双 y 轴时间序列 |
| Fig 2.2 | 散点图：C_k vs α_k（所有家族 × 所有时间点） | 散点图 + LOESS 拟合 |
| Fig 2.3 | 弹性 ε_α(k) 分布（跨家族） | 小提琴图 |
| Fig 2.4 | 资本集中度（Top-5 share）演化 | 分面时间序列（K 三水平） |
| Fig 2.5 | 策略熵 H_strat(t) 在不同 P_eliminate 下 | 分面时间序列 |
| Fig 2.6 | 财富基尼系数演化 vs 市场效率 ρ₁ | 双 y 轴时间序列 |
| Fig 2.7 | Alpha 半衰期 t_half vs P_eliminate | 箱线图 |
| Fig 2.8 | 重生策略存活率曲线 | Kaplan-Meier 式生存曲线 |

### 统计指标

| 指标 | 方法 | 报告格式 |
|------|------|----------|
| 拥挤- Alpha 相关性 | Pearson / Spearman ρ(C_k, α_k) | r ± 95% CI |
| 弹性估计 | 对数-对数回归 ln(α_k) ~ ln(C_k) | β ± SE, R² |
| Granger 因果 | C_k(t−1) → α_k(t) | F 统计量 + p 值 |
| 处理效应（P_eliminate） | 重复测量 ANOVA（P_eliminate 三水平 × 时间） | F + η²_p |
| 资本集中度趋势 | Mann-Kendall 趋势检验 | τ + p 值 |
| E1 vs E2 差异 | 独立样本 t 检验（E1 vs E2 的终态 ρ₁） | t + d |

### 预期发现

1. C_k ↑ → α_k ↓：拥挤度与 Alpha 显著负相关（支持 H2a）
2. 但 α_k 衰减后若无资本流出，不会自发恢复——支持"无演化则无恢复"
3. P_eliminate 越大（选择强度越高），资本越集中，策略熵下降越快
4. 资本集中度与市场效率呈倒 U 型关系（最佳资本分配存在 sweet spot）

## Experiment 3: 复制机制

### 研究问题

> 当成功策略被精确复制（无突变/创新）时，策略同质化如何发生？同质化如何影响市场稳定性与 Alpha 衰减？

### 假说映射

对应 **H3（策略多样性-市场稳定性假说）** 和 **H4（适应性竞争假说）** 的部分检验：
- 复制导致策略单一化 → 市场脆弱性上升
- 无变异的复制 = 无创新的演化 → 种群陷入"演化停滞"（evolutionary stasis）

### 实验处理

在 E2（资本扩张）基础上增加**复制机制**：
- 每 K 期：适应度前 (1−P_eliminate) 的 agent 存活
- 淘汰的 agent 被精确复制取代（`child.strategy = parent.strategy.clone()`）
- 后代财富重置为均等初始值 `W_0 / N_new`
- **无突变**（p_mut = 0）

### 自变量

| 自变量 | 取值 | 目的 |
|--------|------|------|
| 复制策略 | 精确复制 / 财富继承复制（后代继承父代财富比例） | 检验"策略基因"vs"财富基因"的分离效应 |
| 选择压力 | λ_select ∈ {0.5, 3.0, 10.0} | 弱/中/强选择 |
| 演化周期 | K ∈ {100, 200, 500} | 演化速度 |
| 变异（对照） | 无（E3 主体）/ 低突变（σ_mut=0.01, 仅本实验内部对照） | 验证突变必要性 |

**实验矩阵**：2 × 3 × 3 = 18 组（主体）× 5 seeds = 90 次运行

### 因变量（E3 专用）

| 因变量 | 定义 |
|--------|------|
| 策略家族数量衰减率 | dK/dt（策略家族消亡速度） |
| 主导策略占比 | 最大策略家族的 agent 数量占比 |
| 策略同质化时间 | T_homog：主导家族占比首次超过 50% 的期数 |
| 市场脆弱性 | 最大回撤 (max drawdown) 和崩盘频率（|r_t| > 5σ 的期数占比） |
| 演化停滞信号 | 连续多代最佳适应度无改善 |

| Fig 3.6 | 复制模式对比（精确复制 vs 财富继承复制）— K(t) | 双线对比 |

### 统计指标

| 指标 | 方法 | 报告格式 |
|------|------|----------|
| 家族消亡速率 | 指数衰减拟合 K(t) = K₀·exp(−γt) | γ ± SE, R² |
| 同质化时间 | 生存分析（首次通过时间） | 中位数 ± IQR |
| 脆弱性- 多样性关系 | 分段线性回归：极端事件频率 ~ H_strat | 断点 ± CI, R² |
| 选择压力效应 | 单因素 ANOVA（λ_select 三水平 × 终态 H_strat） | F + η² |
| E2 vs E3 差异 | 独立样本 t 检验（终态策略熵、市场效率） | t + d |
| 演化停滞检验 | 配对 t 检验（相邻两代最佳适应度差 vs 0） | t + p 值 |

### 预期发现

1. 无突变的复制 → 策略多样性快速坍缩（几何级衰减）
2. λ_select 越高，同质化越快，但市场脆弱性非线性上升
3. 精确复制 vs 财富继承复制：精确复制导致策略更快同质化（策略基因的独立效应）
4. 同质化后市场出现"脆弱稳定"：表面价格平稳，但极端事件频率显著上升
5. E3 的 Alpha 衰减速度 > E2（策略同质化叠加资本拥挤，双重加速）

## Experiment 4: 复制+突变（完整演化）

### 研究问题

> 在完整达尔文式演化（淘汰→选择→复制→突变）下，策略生态系统呈现怎样的长期动力学？突变能否维持足够的策略多样性以对抗 Alpha 的完全消失？是否存在最优突变率？

### 假说映射

全面检验 **H1–H5**：
- H1：完整演化是否自发涌现弱有效市场
- H2：Alpha 生命周期五阶段是否完整呈现
- H3：策略多样性-市场稳定性倒 U 型关系
- H4：中等复杂策略是否长期生存最优
- H5：制度冲击如何改变策略生态

### 实验处理

**完整演化循环**：每 K 期执行 EvolutionEngine.evolve()
- 淘汰 P_eliminate 比例
- 轮盘赌选择（λ_select 控制选择压力）
- 策略复制（`strategy.clone()`）
- 四维突变（p_mut 控制突变概率，σ_mut/σ_θ/σ_α 控制变异幅度）

### 自变量

| 自变量 | 取值 | 目的 |
|--------|------|------|
| 突变率 | p_mut ∈ {0.05, 0.10, 0.20, 0.40} | 核心操纵变量——检验突变率的最优区间 |
| 变异幅度 | σ_mut ∈ {0.01, 0.03, 0.10, 0.25} | 检验小步变异 vs 大步跳跃 |
| 选择压力 | λ_select ∈ {1.0, 3.0, 10.0} | 选择-突变平衡 |
| 市场制度（子实验 4a） | 基准 / +涨跌停 / +T+1 / +交易成本 / 全A股制度 | 制度冲击 |

**实验矩阵（主体）**：4 × 4 × 3 = 48 组 × 5 seeds = 240 次运行

**子实验 4a（制度冲击）**：取最优参数组合 × 5 种制度 × 5 seeds = 25 次运行

### 因变量（E4 专用）

| 因变量 | 定义 |
|--------|------|
| Alpha 完整生命周期 | 五阶段时间节点（t_emerge, t_peak, t_half, t_extinct） |
| 策略复杂度演化 | 策略的 L1 范数 ‖w‖₁ 或信号熵 −Σ|w_d|·log|w_d| 的种群均值演化 |
| 新生策略存活率 | 突变产生的后代在 500 期内存活的比例 |
| 策略探索-利用平衡 | 新策略类型（全新 ancestor_id）的出现速率 |
| 生态位重叠度 | O_{kℓ}(t)（Pianka 指数）的种群均值 |
| 相变临界点 | 市场从多样态切换到单一态的突变率临界值 p_mut* |
| 制度冲击响应 | 制度变化前后策略熵的变化量 ΔH_strat |

### 统计指标

| 指标 | 方法 | 报告格式 |
|------|------|----------|
| 突变率最优区间 | Response surface 分析 | 最优 p_mut ± CI |
| 相变检测 | 分段线性回归断点检测 | p_mut* ± SE |
| 倒 U 型检验 | 二次回归 H_strat ~ β₁·H_strat + β₂·H_strat² | β₂ < 0 的 t 检验 |
| Alpha 生命周期阶段时长 | 生存分析（各阶段持续时间的 Kaplan-Meier） | 中位数 ± IQR |
| 选择-突变平衡 | 稳态 H_strat 对 λ_select 和 p_mut 的曲面拟合 | R² |
| 制度冲击效应 | 配对 t 检验（冲击前后 H_strat） | t + d + 95% CI |
| E3 vs E4 差异 | 独立样本 t 检验（终态 H_strat, ρ₁, 极端事件频率） | t + d |
| 策略复杂度趋势 | Mann-Kendall 趋势检验 | τ + p 值 |
| 新生策略存活率 | Logistic 回归（存活 ~ 突变幅度 + 父代适应度） | OR + 95% CI |

### 预期发现

1. **存在最优突变率** p_mut* ≈ 0.10–0.20：过低→策略过早同质化；过高→有利变异被噪声淹没
2. Alpha 生命周期五阶段在 p_mut 适中时完整呈现：探索→爆发→拥挤→衰退→（部分恢复或灭绝）
3. 策略复杂性随演化代数上升但趋于稳定（"军备竞赛"存在上限）
4. 突变维持的多样性形成"红皇后效应"——策略必须不断演化以维持原地（持续 Alpha≈0）
5. 制度冲击（涨跌停、T+1）系统性改变可存活策略类型组成
6. 与 E3 对比：突变使 Alpha 半衰期延长 2–5 倍，极端事件频率降低 40–60%

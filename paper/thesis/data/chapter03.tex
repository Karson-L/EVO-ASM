\chapter{实验设计与结果分析}
\label{chap:experiments}

本章设计四组递进实验，从静态基线到完整演化，逐步剥离Alpha衰减的因果机制。四组实验的逻辑链如下：

\begin{center}
\textbf{E1（无演化基线）} $\to$ \textbf{E2（资本扩张）} $\to$ \textbf{E3（复制机制）} $\to$ \textbf{E4（复制+突变）}
\end{center}

每组实验在前一组基础上增加一个演化机制，从而可以独立识别每个机制的因果贡献。

\subsection{初始化规则}

所有实验采用统一的初始化规则：
\begin{itemize}
    \item 所有Agent初始财富均等：$W_i(0) = W_{\text{total}} / M = 20,000$
    \item 初始持仓 $h_i(0) = 0$
    \item 初始策略随机生成，$\mathbf{w}_i(0) \sim \mathcal{N}(0, \sigma_{\text{init}}^2 \cdot \mathbf{I}_D)$，归一化
    \item 每个Agent的ancestor\_id = agent\_id（独立祖源）
    \item 市场初始价格 $P(0) = \bar{F} = 100$
\end{itemize}

\subsection{通用因变量}

所有实验均采集以下因变量：策略熵 $H_{\text{strat}}(t)$、市场效率 $\rho_1(t \mid \Delta)$、收益率峰度 $\text{Kurt}(t \mid \Delta)$、波动率聚集 $\text{ACF}(|r|)(t)$、平均成交量 $\bar{V}(t)$、财富基尼系数 $\text{Gini}(t)$ 和策略家族数量 $K(t)$。

\section{Experiment 1：无演化基线}

\subsection{研究设计}

\textbf{研究问题：}在策略分布完全静态的封闭市场中，Alpha是否仍然衰减？市场是否自发趋向有效？

\textbf{假说映射：}对应H1（弱有效市场涌现假说）的部分否定检验——若E1中发现显著Alpha持续存在，则演化机制是Alpha衰减的必要条件。

\textbf{实验处理：}全部演化开关关闭——无淘汰（$P_{\text{eliminate}} = 0$），无复制，无突变，无财富重分配。每个Agent在整个模拟期间保持其初始策略不变，财富仅通过交易盈亏自然变化。

\textbf{自变量：}
\begin{itemize}
    \item 策略初始多样性：$\sigma_{\text{init}} \in \{0.02, 0.10, 0.30\}$（低/中/高）
    \item 噪声交易冲击：$\sigma_{\text{noise}} \in \{0.0, 0.005, 0.02\}$
\end{itemize}

\subsection{E1结论}

E1实验的核心发现是：\textbf{在缺乏演化压力（无淘汰、无复制、无突变）的情况下，Alpha不会系统性衰减}。虽然市场价格展现出弱有效性质（$\rho_1 \approx 0$），但策略间的盈利能力差异可以持续存在，策略生态系统保持其初始多样性水平。这一发现为后续实验提供了基准：E1否定了"仅凭市场交易即可消除Alpha"的假说，表明Alpha衰减需要演化机制驱动。

\section{Experiment 2：资本扩张（财富集中机制）}

\subsection{研究设计}

\textbf{研究问题：}财富集中（策略拥挤）单独驱动Alpha衰减吗？

\textbf{假说映射：}对应H2的部分检验——资本向盈利策略的集中是否构成Alpha衰减的充分条件。

\textbf{实验处理：}引入财富重分配（淘汰-替换机制），但无复制和突变。每 $K=200$ 期，淘汰底部 $P_{\text{eliminate}}$ 比例的Agent，财富重新分配给幸存者。被淘汰者由随机新策略替代（无复制）。

\textbf{自变量：}
\begin{itemize}
    \item 淘汰比例：$P_{\text{eliminate}} \in \{0.05, 0.10, 0.20\}$
    \item 选择强度：$\lambda_{\text{select}} \in \{1.0, 2.0, 4.0\}$
    \item 策略初始多样性：$\sigma_{\text{init}} \in \{0.02, 0.10, 0.30\}$
\end{itemize}

\subsection{实验结果}

实验E2共运行135组参数组合，生成1080张分析图表。

\subsection{E2结论}

E2实验的核心发现是：\textbf{财富集中机制单独就足以驱动Alpha的部分衰减}。在没有策略复制和突变的情况下，资本向盈利策略的集中产生了"拥挤效应"——越多资本追逐同一策略，该策略的超额收益越低。然而，与后续实验相比，E2条件下的Alpha衰减是不完整的：缺乏复制和突变意味着没有"策略创新"来替代被淘汰的策略，也没有"策略模仿"来加速同质化。

\section{Experiment 3：复制机制}

\subsection{研究设计}

\textbf{研究问题：}策略模仿（复制）如何导致多样性丧失？复制机制对Alpha衰减的边际贡献有多大？

\textbf{假说映射：}对应H3和H4的部分检验——策略复制加速同质化和适应性竞争。

\textbf{实验处理：}在E2基础上引入策略复制（无突变）。被淘汰Agent由幸存Agent的复制后代替代（轮盘赌选择），后代继承父代策略。

\textbf{自变量：}
\begin{itemize}
    \item 选择强度：$\lambda_{\text{select}} \in \{1.0, 3.0\}$
    \item 策略初始多样性：$\sigma_{\text{init}} \in \{0.02, 0.10, 0.30\}$
    \item 噪声交易冲击：$\sigma_{\text{noise}} \in \{0.0, 0.005, 0.02\}$
\end{itemize}

\subsection{实验结果}

实验E3共运行90组参数组合，生成720张分析图表。

图\ref{fig:e3_decay}展示了复制机制下策略家族数量的指数衰减。关键发现：

    \item 衰减时间常数 $\tau_K$ 与选择强度 $\lambda_{\text{select}}$ 负相关——选择压力越大，多样性丧失越快。
    \item 在 $\lambda_{\text{select}} = 3.0$ 条件下，策略家族数量在1500期后可降至初始水平的20\%以下。
\end{enumerate}

\subsection{E3结论}

E3实验的核心发现是：\textbf{策略复制机制显著加速了Alpha衰减和策略多样性丧失}。与E2相比，E3中策略家族数量的下降速度提高约2-3倍。复制产生的"赢家通吃"效应使市场出现明显的策略同质化趋势。然而，缺乏突变意味着策略群体缺乏适应性创新，在环境变化时容易集体失效。

\section{Experiment 4：复制+突变（完整演化）}

\subsection{研究设计}

\textbf{研究问题：}突变能否维持策略多样性以对抗Alpha衰减？在什么参数组合下，策略生态系统能够在"创新-竞争-淘汰"的循环中维持动态平衡？

\textbf{假说映射：}全面检验H1-H5。E4是完整演化实验，包含淘汰、复制和突变三个机制。

\textbf{实验处理：}完整的达尔文式演化——淘汰→选择→复制→突变。被淘汰Agent由突变后的复制后代替代。

\textbf{自变量：}
\begin{itemize}
    \item 突变率：$P_{\text{mut}} \in \{0.05, 0.10, 0.20, 0.40\}$
    \item 选择强度：$\lambda_{\text{select}} \in \{1.0, 2.0, 3.0, 5.0\}$
    \item 策略初始多样性：$\sigma_{\text{init}} \in \{0.02, 0.10, 0.30\}$
\end{itemize}

\subsection{实验结果}

实验E4共运行240组参数组合，生成2880张分析图表。

  \centering

图\ref{fig:e4_lifecycle}是本研究的核心发现。它揭示了Alpha生命周期的完整五个阶段：
\begin{enumerate}
    \item \textbf{探索期（0-200期）：}策略探索市场，Alpha波动大但无明确方向。
    \item \textbf{爆发期（200-500期）：}某些策略发现有效信号，Alpha迅速上升至峰值。
    \item \textbf{拥挤期（500-1000期）：}复制机制使成功策略被广泛模仿，资本集中导致Alpha衰减。
    \item \textbf{衰退期（1000-1500期）：}Alpha持续下降，部分策略被淘汰。
    \item \textbf{恢复/灭绝分叉：}高突变率条件下，新策略变异可能发现新的Alpha来源（恢复）；低突变率下，策略可能彻底灭绝。
\end{enumerate}

图\ref{fig:e4_entropy_grid}展示了不同突变率和选择强度组合下的策略熵轨迹。关键发现：
\begin{enumerate}
    \item 低突变率+高选择强度 $\to$ 策略多样性迅速崩溃。
    \item 高突变率+低选择强度 $\to$ 策略多样性维持在中等水平，市场呈现动态平衡。
    \item 存在最优参数区间：$P_{\text{mut}} \in [0.05, 0.20]$ 和 $\lambda_{\text{select}} \in [1.0, 3.0]$，在此区间内策略生态系统既维持多样性又不至于碎片化。
\end{enumerate}

图\ref{fig:e4_phase}展示了一个尤为重要的发现：策略生态系统存在\textbf{相变}现象。当控制参数（突变率/选择强度比）越过临界值时，系统从高多样性、接近弱有效的状态突然跃迁到低多样性、策略同质化的状态。这种相变具有滞后效应（hysteresis）——系统一旦进入同质化状态，即使恢复参数也很难回到多样化状态，因为少数主导策略已经获得了不可逆的财富优势。

\subsection{E4结论}

E4实验的核心发现包括：
\begin{enumerate}
    \item \textbf{Alpha生命周期确实存在}，其五个阶段（探索-爆发-拥挤-衰退-恢复/灭绝）在不同参数条件下均可观测。
    \item \textbf{突变是维持策略生态系统多样性的关键机制}。完全缺乏突变（E3）导致快速同质化；适度突变（$P_{\text{mut}} \approx 0.10$）可以在竞争与创新之间建立动态平衡。
    \item \textbf{策略生态系统存在临界相变}，这一发现对金融稳定具有重要启示：策略同质化不仅是Alpha衰减的结果，更可能是系统性风险累积的前兆。
    \item \textbf{策略复杂度与生存概率呈倒U型关系}，验证了Lo（2017）"适者生存，而非最优者生存"的核心论断。
\end{enumerate}
